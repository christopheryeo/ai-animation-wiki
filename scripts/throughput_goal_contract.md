# Ingestion Throughput Goal Contract

Measure throughput only after approved source material exists. Establish a fresh baseline from
the AI Animation wiki; never inherit performance counts from another customer.

Acceptance requires deterministic input selection, complete provenance, zero skipped validation
errors, reproducible catalogues, no production writes, and a rollback-safe run manifest. Optimise
only after correctness tests pass. Report input count, completed count, held count, elapsed time,
peak memory, validation results, and the exact repository revision used.
