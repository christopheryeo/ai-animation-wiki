# Query Procedure

1. Resolve names and aliases through generated entity catalogues.
2. Read only the smallest canonical Markdown notes needed to answer.
3. Prefer saved summaries and provenance-backed relationships.
4. Expand to linked articles only when the summary is insufficient.
5. Distinguish current facts from historical records and generated projections.
6. Never invent an entity, relationship, source, or monitoring result.
7. If the empty starter has no supporting notes, answer that no content is registered.
8. Cache only source-grounded answers and record the procedure version.

External model use is optional and requires separately configured credentials. Local resolution
and empty-state queries must work without network access.
